# An-lisis-y-Exploraci-n-de-datos-sensor-
El objetivo principal de este proyecto es implementar un flujo de trabajo completo de Ciencia de Datos utilizando el lenguaje de programación Python. A través de este proceso, se busca transformar datos en bruto (raw data) extraídos directamente de los servidores del Servicio Meteorológico Nacional en información estadística de alto valor.
